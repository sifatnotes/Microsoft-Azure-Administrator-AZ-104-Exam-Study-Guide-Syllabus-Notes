## Exam Overview

The **AZ-104: Microsoft Azure Administrator** exam measures your ability to accomplish critical operational tasks: implementing, managing, and monitoring identity, governance, storage, compute, and virtual networks in a cloud environment.

| Parameter | Details |
| :--- | :--- |
| **Vendor** | Microsoft |
| **Exam Code** | AZ-104 (Azure Administrator Associate) |
| **Delivery Provider** | Pearson VUE / Certiport |
| **Passing Score** | 700 / 1000 (Scaled Score) |
| **Format** | 40–60 Questions (Multiple Choice, Drag-and-Drop, Case Studies, Lab Scenarios) |
| **Renewal** | Valid for 1 year; renewable annually via free online assessment on Microsoft Learn. |

---

## Target Audience

- **Cloud Administrators & System Engineers** implementing operational infrastructure in Azure.
- **DevOps Engineers** provisioning foundational storage, compute, and networking for CI/CD pipelines.
- **IT Infrastructure Specialists** migrating on-premises workloads to hybrid or multi-region Azure environments.
